# Accepted-model reference figures

These PNG files are deterministic reference outputs generated from the frozen
accepted-model package. They support visual inspection in addition to the
machine-readable checks performed by `scripts/verify_reproduction.py`.

- `model/`: fitted and strict nested-validation overview.
- `diketones/`: reaction-progress and uncertainty figures for a-f.
- `contribution_series/`: within-series contribution/experiment comparisons.
- `comparators/`: accepted-model comparisons.
- `spatial_analysis/`: coefficient stability and realized-effect maps.

Contribution cubes are optional display artifacts and remain excluded from
Git. The reusable export and viewer source code is retained in `libs/` and
`scripts/viewers/`.
