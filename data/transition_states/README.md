# Transition-state coordinates and energies

`Optimized_TS_coordinates_and_corresponding_energies.xlsx` is the compact
workbook submitted with the accompanying manuscript. It contains optimized
coordinates, corrected energies and relative barriers for the transition-state
analysis, a compact barrier summary, and EDA results.

This workbook supports the quantum-chemical mechanistic analysis. It is not an
input to the machine-learning model and is not required to reproduce the
canonical results under `data/current_model/`.

The worksheet name `summery` is retained verbatim so that this archived copy is
byte-identical to the submitted workbook.
